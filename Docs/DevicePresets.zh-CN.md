# 设备预设

连接 Serial 输出后，点击标题栏的调节图标打开“设备运动预设”。
功能对齐固件浏览器配置器 `configurator/src/pages/Tuning.tsx` 的预设部分：

- 平移 L0/L1/L2、旋转 R0/R1/R2 分组；显示设备当前 V/A/J 和最多 32 组命名预设。
- 应用预设，可选择同时保存为开机参数。
- 直接编辑 V/A/J，临时应用或保存为开机参数。
- 将设备当前值保存为新预设；覆盖同名预设需要勾选“允许覆盖”。
- 删除前勾选“确认删除选中预设”；删除不改变当前参数。
- 多个预设数值一致时显示“同值”；本窗口明确应用/保存的名称或唯一匹配项显示“当前”。
- 状态区展示错误，通信详情保留操作及回复。

窗口打开时暂停视频和本串口的动作输出。复用已打开的 SerialPort，不重新开端口；
V4 先停止旧会话并等待 STOP 应答。关闭后恢复串口输出，视频需手动继续；固定/轮询输出按其原模式恢复。
V4 下次播放只查询当前位置，并从脚本重新推导本次会话 V/A/J；不会因这些旧实时轨迹预设自动缩幅。

需要支持 `$<id>` 配置 API 的 P4 固件。使用 `hello`、`presets L/R`、`set/settemp`、`sh Lpreset/Rpreset`，
与浏览器配置器共用 CTWA/COBS/CRC32 协议；不需要打开浏览器配置器，也不切换 Shell 模式。
无应答会显示超时并断开输出，不自动重放写操作。

固件当前逐项写入 V/A/J；若某项失败，界面提示可能部分生效并尝试重新读取实际值。
这不是三项参数的原子事务。当前已完成 Release 自包含单文件编译，尚无设备通信和 UI E2E 验证。
