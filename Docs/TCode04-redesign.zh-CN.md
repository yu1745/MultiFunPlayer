# V4 脚本会话 V/A/J（2026-10-16）

每次播放按实际输出节点推导独立的平移/旋转 V/A/J，通过 BEGIN 提交给 P4。
V4 不查询设备 V/A/J，不使用设备旧实时轨迹设置自动缩幅，不保留旧版字段兼容。

## 数据与规划

- QUERY 0 获取时钟、状态、容量；POSE 6 只获取模型 1 和六轴当前位置（13 字段）。
- BEGIN 1 共 13 字段：`1,请求号,启动号,会话号,轴掩码,起始微秒,1,Tv,Ta,Tj,Rv,Ra,Rj`。
- 六个正数按 1e6 编码，编码范围 1..100000000000；位置查询按 1e6，APPEND 位置按 10000。
- 七次曲线解析峰值：`V=2.1875 D/T`、`A=7.513189 D/T²`、`J=52.5 D/T³`。
  对处理过播放速度、偏移、输出范围和量化的节点逐段计算，各组取最大值，除以 0.98 后向上取整。
- MFP/XTP 保留媒体节点幅度与时刻，初始定位按脚本包络延长（至少一秒）；全静止组按一秒
  初始位移推导，完全无位移用 0.01 下限。极端脚本超出协议数字范围时报错。
- 预定时 trace 工具按包含初始定位的完整计划推导；所有定位和媒体段必须通过量化后复核。

## 固件执行

会话持有独立、不可变的六项包络。APPEND 原子校验每段峰值，超限错误 9，模型不支持错误 10。
旧 BEGIN 字段数被拒绝。ACK 100 的 22 字段保持不变，20 字段 LIMITS 和配置版本已删除。
TRAJECTORY_* V/A/J 继续用于旧实时控制，不再使 V4 会话失效。停止/故障从已接受的 p/v/a
按会话包络连续制动，直到旧控制器能够接管；不跳变状态。电机就绪、IK 和电机保护仍有效。
脚本包络表示轨迹需求，不表示硬件额定能力。L0/L1/L2/R1/R2 为前六台电机耦合机构，R0 独立。

## 链路

继续使用数字 `!4` 帧与 CRC。C3 透明转发，无需修改固件。配置 API 的 `$<id>` 与 V4 独立分流。
QUERY/POSE 使用独立查询序号；BEGIN 超时须先查询确认会话归属，再对已创建会话 STOP。
暂停、拖动、变速或更换脚本须停止旧会话并重新规划。停止未获 ACK 必须报告。

完整规范见 TCode-Specification-v0.4/spec/0.4-buffered.md。
