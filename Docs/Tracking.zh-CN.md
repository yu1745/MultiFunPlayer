# 动作跟随监测

在 Serial 输出选择 **Buffered Update**，启用“实时跟随监测”，点击串口输出标题栏的折线图按钮。
窗口独立显示，不阻挡播放器操作。需使用支持 `!TRK1` 的配套 P4 固件；旧固件会显示不支持，
播放本身保持兼容。

921600 默认 50 Hz 回传，界面 10 Hz 刷新；115200 自动降为 20 Hz，230400 为 25 Hz。
原生 USB 的波特率设置不等于无线吞吐，判断效果时同时查看实际回传率和数据质量。

面板提供目标／估计实际曲线、实时位置误差、RMS、P95、延迟、幅度保持率、超调、稳定周期下的
频率与相位，以及反馈年龄、缺帧、CRC、正解有效率、闭合残差、采样覆盖和回传积压估计。
窗口可选 2/4/8/12 秒；“重置本机统计”只清空 MFP 分析，不影响设备日志或动作。

目标是 P4 规划后的杆尖动作；实际由六台电机编码器和固定 CAD 模型估计，不能把一台电机等同于
某个动作轴。L0/L1/L2 用 mm，R0/R1/R2 用度，R0 独立由 M7 测量。电机诊断展开后可查看
最终量化指令与对应反馈。模型不能完整测量连杆弹性、间隙及附件变形。

RMS/P95 保留真实滞后误差；幅度先做延迟对齐再回归求增益，100% 不代表整体准确率 100%。
延迟正值表示滞后；传感器时间使用 P4 收到反馈的时刻，仍含电机内部滤波和 CAN 延迟。
相位只在至少两个稳定周期时显示。静止、匀速、幅度太小、相关性不足或周期混叠时显示原因，
不会把“无法估计”显示成零。超调仅在完整转折或到位保持后计算。
相位按主频正弦／余弦拟合，折算到 ±180°；即使整周期延迟不唯一，主频相位和基波幅度比仍可能
可靠，界面会区分它们与绝对时间延迟。

超过约 500 ms 无新鲜快照或回传积压时，指标变为不可用，历史曲线灰显。跟随误差的计算使用 P4
源端时间，不以串口到达时间估算运动延迟。CRC 坏帧不影响播放 ACK；订阅 1.5 秒未续约自动停止。
复杂正解与统计在后台分析线程运行，不阻塞串口接收器或 WPF UI。

协议与完整计算口径见配套固件仓库 `docs/tracking.md`。当前仅是监测，不自动调参或改变动作。

测试：`dotnet test Source/MultiFunPlayer.TCode.Tests/MultiFunPlayer.TCode.Tests.csproj`。
`TestData/tracking-cad.frames` 由配套固件 `test/tracking_native` 用生产 CAD 逆解与封装代码生成，
覆盖七电机异步反馈年龄；这是模拟数据，不是实机测量记录。
